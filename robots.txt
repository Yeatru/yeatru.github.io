# Yeatru Sourcing — robots.txt (AI-citation first-party revision 2026-10-22)
#
# Strategy:
#   * AI SEARCH bots (that answer user questions and cite sources) are
#     fully allowed at zero crawl delay — we want them to index and
#     surface Yeatru as a primary source, not a throwaway item in a list.
#   * TRAINING bots (that ingest your content without attribution into
#     their foundation model) are still allowed to READ / SEARCH pages,
#     but we disallow private API/export endpoints that would let them
#     scrape the full catalog without returning a citation.
#   * Public product pages, static HTML blog, the rankings hub and the
#     schema-rich About page stay open for every bot — AI searchers
#     need exactly that.
